## Adobe Stock and Shutterstock Keywording

Effective keywording starts with accurate descriptions of the image's subject, concept, location, activity, and intended commercial use.

- Prioritize relevant keywords over keyword quantity.
- Put the most important keywords first where the agency uses keyword order.
- Avoid irrelevant or misleading terms.
- Check each marketplace's current metadata requirements.
- Use IPTC/XMP metadata to keep titles, descriptions, and keywords organized.
